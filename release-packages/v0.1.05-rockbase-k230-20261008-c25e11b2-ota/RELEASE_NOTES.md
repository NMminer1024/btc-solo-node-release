### Improved
- On a fresh flash, the Bitcoin data partition is now about 3.5 GB larger, giving the node much more headroom before the disk can fill up.
- The system now keeps its internal logs trimmed automatically, so long-running devices no longer risk running out of space on the settings partition.

### Fixed
- If the Wi-Fi connection hangs, the node now recovers it on its own instead of freezing and rebooting the whole device.
