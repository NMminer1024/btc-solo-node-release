### Improved
- The Network page now shows your IP address and MAC address on a single clean line.
- The Bitcoind page now shows how long the device has been running (uptime) in the corner.
- The Stratum page no longer shows a blank placeholder for total hashrate when no miner is connected.
- The block height numbers on the Bitcoind page now use a consistent, easier-to-read color.

### Fixed
- Changing the timezone no longer gets stuck on "Applying"; it now finishes immediately.
